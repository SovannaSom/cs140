CSS

1. Explain the difference between inline, embedded, and external CSS.

Inline CSS is used to style an element by writing CSS directly inside the HTML element.

Embedded CSS is used to style paths by typing directly inside the HTML file

External CSS is used to style separately from CSS file to the HTML file

2.Explain why you should only use external CSS.

Because using external CSS is easier to organized and style specific elemants in HTML and provides the same style on multiple pages.

3. What is a selector used for?

Selector is used to choose which paths need to be styled.
