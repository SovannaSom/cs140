CSS Selectors

1.List out the different ways to select an item.

  • Tag name
  • Decendent
  • A bunch of other stuff
  • ID: use(#), no space, letter a-z, symbols
  • Class: use dot(.)

2. What is the difference between an ID and a Class?

ID need to be unique while Class can be reused.

3. What is the difference between a SPAN tag and a DIV tag?

Span allows us to add add Class. DIV collects or group things together and also causes break line.

4. What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

A HEADER, MAIN, or FOOTER tells us the content or meaning of our webpage. But DIV is only used to group and organize the webpage.

5. What are the different ways to select a color?

Colors can be selected using color names, HEX codes, RGB values.
