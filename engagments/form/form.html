Answer

1. The form tag has an "action" attribute. What does it do?
>>>it tells browser where to send the form information after users submit.

2. The form tag has a "method" attribute. What does it do?
>>>The method attribute tells browser how to send the form information to destination.

3. What is the difference between a "POST" and a "GET"?
>>>POST sends information in the request body. GET sends information through the URL.

4. How do you fill in a form control with a pre-set value, and how is that different from a placeholder? Answer for each of these: text box, textarea, select box, checkbox, and radio button.
>>>A pre-set value is information that is already filled in a form to to help user input information. A placeholder is a hint that tells the user what to type. For a text box, use value. For a textarea, write text between the opening and closing tags. For a select box, use selected. For a checkbox and radio button, use checked.

5. List all the form controls that HTML5 added. Which ones did you put in your form?
>>>All HTML5 Form Controls are email, URL, telephone, search, number, range, date, time, month, week, color, and datetime-local. I added email, date, and number to my form.
