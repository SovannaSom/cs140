1. Why don't we use the border attribute?
Because it is outdated.

2. What is the easiest way to color every other row a different color?
The easiest way to color every other row a different color is to use the CSS structural pseudo-class :nth-child(even) or :nth-child(odd).

3. What does the value in the parentheses of your structural pseudo-class mean? Give one other value you could use and which rows it would select.
It tells the browser which rows to select. For example, if i choose even, it will color row 2, 4, 6, and all even number rows.
